## 01｜孔子生平

> 開場　·　約 0 分 22 秒　·　1 個步驟

### 講稿

大家好，今天要介紹的是孔子的一生。

畫面裡這座霧中的小城，是春秋時代的魯國。站在石台上的那位老人，就是孔子；圍坐在他身邊的，是他的學生。

接下來，我們跟著他從魯國陬邑的一間茅草屋出發，走完這七十三年。

## 02｜吾少也賤

> 少也賤　·　約 0 分 44 秒　·　3 個步驟

### 講稿

孔子名丘，字仲尼，西元前 551 年出生在魯國的陬邑，大約是今天山東曲阜一帶。

父親叔梁紇在他很小的時候就過世了，他是由母親顏氏一手帶大的，家裡並不富裕。

**【按 → 下一步】**

年輕的孔子做過很基層的差事。他當過「委吏」，負責管倉庫，他說：帳目算對就好。也當過「乘田」，負責管牛羊，他說：把牛羊養得壯壯的就好。

**【按 → 下一步】**

後來他回想這段日子，說了一句話：「吾少也賤，故多能鄙事。」我小時候地位低微，所以學會了很多粗活。這句話很誠實，也說明了他一生的起點。

## 03｜十有五而志于學

> 志于學　·　約 0 分 41 秒　·　3 個步驟

### 講稿

《論語・為政》裡，孔子說自己「十有五而志于學」：十五歲就立定志向要求學。

他沒有出身名門，也沒有固定的老師，所以他的方法是：哪裡有懂的人，就向誰學。

**【按 → 下一步】**

根據《史記》記載，他曾經到周朝的都城，向老子請教禮制，這段相遇後人多半當作傳說來看。他也向魯國的樂師師襄學琴，一首曲子反覆練，練到能體會作曲者的為人，才肯換下一首。

**【按 → 下一步】**

所以他說：「三人行，必有我師焉。」看到別人的優點就學，看到缺點就拿來反省自己。

## 04｜杏壇有教無類

> 杏壇設教　·　約 1 分 02 秒　·　3 個步驟

### 講稿

大約三十歲前後，孔子開始收學生、私人講學。

在那個時代，教育是貴族的事，叫做「學在官府」。孔子把它帶出了貴族的圍牆。畫面中這座石台叫「杏壇」，典故出自《莊子》，後來成了教育的代名詞。

**【按 → 下一步】**

《史記》說他的弟子大約有三千人，其中精通禮、樂、射、御、書、數六藝的有七十二人。

而他收學生的門檻很低：「自行束脩以上，吾未嘗無誨焉」，只要帶一束乾肉當見面禮，他都願意教。這就是「有教無類」。

**【按 → 下一步】**

他也會看學生的個性給不同的答案。子路和冉有問了同一個問題：「聽到了就要馬上去做嗎？」孔子對子路說：你有父兄在，怎麼能馬上做？對冉有卻說：聽到了就去做。

因為子路太衝動，要拉他一下；冉有太退縮，要推他一把。後人把這叫做「因材施教」。

## 05｜從中都宰到大司寇

> 仕魯　·　約 0 分 52 秒　·　3 個步驟

### 講稿

大約五十一歲，孔子終於有機會從政。魯定公任命他為中都宰，也就是一個地方的首長。《史記》說他治理一年，四方都來仿效。

之後他升任司空、再升為大司寇，掌管司法。這是他一生最接近實現理想的時候。

**【按 → 下一步】**

西元前 500 年，魯定公和齊景公在夾谷會盟，由孔子陪同。齊國想用武力威嚇，孔子依禮據理力爭，最後齊國歸還了之前侵占的魯國土地。

**【按 → 下一步】**

但魯國真正的權力，掌握在季孫、叔孫、孟孫三家手上，史稱「三桓」。孔子主張拆掉三家私邑的城牆，史稱「墮三都」。拆了兩座，第三座失敗，改革半途而廢，他和權臣之間也有了裂痕。

## 06｜周遊列國十四年

> 周遊列國　·　約 1 分 26 秒　·　5 個步驟

### 講稿

後來齊國送了一批歌舞女樂給魯國，執政的季桓子接受了，連續三天不上朝。孔子知道理想在魯國已經走不下去，大約五十五歲那年，帶著弟子離開了魯國。

這一走就是十四年，到過衛、宋、鄭、陳、蔡等國，想找一位願意實行他主張的國君。

**【按 → 下一步】**

第一個難關在匡。匡人把孔子誤認成曾經欺壓他們的陽虎，把他們圍了五天。孔子說：「文王既沒，文不在茲乎？」周文王雖然不在了，文化不就在我身上嗎？

**【按 → 下一步】**

到了宋國，孔子在一棵大樹下和弟子習禮。宋國的司馬桓魋想殺他，把大樹拔了。孔子說：「天生德於予，桓魋其如予何？」上天把德行交給我，桓魋能拿我怎麼樣？

**【按 → 下一步】**

到了鄭國，他和弟子走散了，一個人站在東門外。有人說他看起來「累累若喪家之狗」，子貢據實告訴他，孔子反而笑了：「說得對！說得對！」

**【按 → 下一步】**

最艱難的是在陳、蔡之間斷了糧，隨行的人都餓病了。子路生氣地問：君子也會這麼窮困嗎？孔子說：「君子固窮，小人窮斯濫矣。」君子在窮困時仍守得住自己，小人窮困了就什麼都做得出來。

## 07｜回到魯國整理典籍

> 返魯　·　約 0 分 42 秒　·　2 個步驟

### 講稿

西元前 484 年，六十八歲的孔子被迎回魯國。周遊了十四年，他沒有找到願意重用他的國君。

回到魯國後，他不再求官，把最後的歲月留給教學，以及整理古代的典籍。

**【按 → 下一步】**

根據《史記》記載，他編訂了《詩》《書》，整理了禮和樂；晚年特別喜歡讀《易》，把串竹簡的皮繩都翻斷了好幾次，這就是「韋編三絕」。他也根據魯國的史書修了《春秋》。

不過要說明一下，這些說法多半出自後世的記載，孔子實際參與到什麼程度，學界還有不同的看法。

## 08｜天喪予天喪予

> 晚年　·　約 0 分 41 秒　·　3 個步驟

### 講稿

孔子的晚年，接連失去了最親近的學生。

他最欣賞的弟子顏回早逝。孔子哭著說：「噫！天喪予！天喪予！」老天要亡我啊！

**【按 → 下一步】**

不久之後，跟著他最久、個性最直的子路，在衛國的內亂中戰死。據《左傳》記載，子路臨死前說「君子死，冠不免」，把被砍斷的冠纓重新繫好才倒下。

**【按 → 下一步】**

西元前 479 年，孔子辭世，享年七十三歲，葬在魯城北邊的泗水旁。

弟子們為他守喪三年才離開。只有子貢在墓旁搭了一間小屋，又多守了三年，一共六年。

## 09｜從心所欲不踰矩

> 一生　·　約 0 分 33 秒　·　2 個步驟

### 講稿

最後，用孔子回顧自己一生的話作結。

吾十有五而志于學，三十而立，四十而不惑，五十而知天命，六十而耳順，七十而從心所欲，不踰矩。

**【按 → 下一步】**

孔子沒有親手寫下自己的學說。是他的弟子和再傳弟子，把他的言行編成了《論語》。

一個出身清寒、做過倉庫管理員的人，一輩子沒有當上大官，卻因為「學而不厭，誨人不倦」，被後世尊為「至聖先師」。
